# Require automated behavioral proof before publishing

V1 treats automated, user-observable tests as the publication gate: an exhaustively tested JavaScript semantic core, React Native Testing Library integration coverage, shared device scenarios across native iOS 27 and fallback iOS 27, iOS 26, and Android, Reassure checks on critical render paths, and clean-fixture validation of the exact package artifact. `agent-device` is the preferred device harness: version 0.20.10 is pinned because it includes the published selector-targeted drag gesture, including continuous source hold, timed movement, and destination hold ([callstack/agent-device#1567](https://github.com/callstack/agent-device/pull/1567)), together with the current iOS runner recovery and exact-target resolution fixes. Pointer planning is capability-based and preserves the shared semantic destination: Detox targets the named row's upper quarter for insertion before it, while Agent Device's center-only selector drag targets the predecessor on native SwiftUI. Detox remains the fallback for contracts that `agent-device` cannot express, including custom accessibility-action dispatch and lifecycle mutation during an in-flight gesture. Routine manual QA, implementation-detail assertions, silent retries, and uncovered contractual behavior are rejected because neither engine parity nor release confidence should depend on a maintainer repeating a checklist.
