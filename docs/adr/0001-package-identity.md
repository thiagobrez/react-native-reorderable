# Keep the react-native-reorderable identity

The npm package and GitHub repository are both named
`react-native-reorderable`. Although the name is close to the established
`react-native-reorderable-list`, the exact npm name is available and describes
the broader API accurately; changing it after publication would disrupt every
import, document, and search result. The positioning line is “Virtualized,
sectioned and native reorder and drag-and-drop library for React Native,” with
supporting documentation clarifying that the native engine is used where
available and the cross-platform fallback is used elsewhere.
