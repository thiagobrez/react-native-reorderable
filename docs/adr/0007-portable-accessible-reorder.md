# Make accessible reorder semantic and engine-independent

V1 guarantees accessible reorder and drop on both engines through library-owned semantic actions that bypass pointer mechanics while using the same identity-based commit, reconciliation, and callback path. Reorderable items expose localized move-earlier and move-later actions; acting on a selected item moves the complete application-owned selection atomically in canonical order, while drop zones accept that selection through a localized drop action. This design preserves VoiceOver and TalkBack parity despite SwiftUI offering no programmatic reorder control and React Native offering no portable keyboard-only event surface; SwiftUI's automatic accessible drag may remain as additional native presentation but is not contractual.

The library owns action availability, boundary behavior, focus retention, position metadata, reconciliation, and announcements while applications own meaningful element labels, accessible selection controls, and localized strings. Keyboard-only reorder without a screen reader is an acknowledged v1 gap. Shipping requires automated semantic-action coverage across both engines and a one-time physical iOS 27 VoiceOver check of the React Native-to-SwiftUI hosting boundary.
