# Require automated behavioral proof before publishing

V1 treats automated, user-observable tests as the publication gate: an exhaustively tested JavaScript semantic core, React Native Testing Library integration coverage, shared device scenarios across native iOS 27 and fallback iOS 27, iOS 26, and Android, Reassure checks on critical render paths, and clean-fixture validation of the exact package artifact. `agent-device` is the preferred device harness: its selector-targeted drag gesture, including continuous source hold, timed movement, and destination hold, is a merged upstream feature ([callstack/agent-device#1567](https://github.com/callstack/agent-device/pull/1567)) rather than a prototype and becomes available here with the next published version; Detox remains the fallback until that release is adopted. Routine manual QA, implementation-detail assertions, silent retries, and uncovered contractual behavior are rejected because neither engine parity nor release confidence should depend on a maintainer repeating a checklist.
